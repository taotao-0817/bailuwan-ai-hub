# 架构与扩展说明

## 进程与数据流

```text
React / Three.js 浏览器
     │ 同源 Cookie 会话 + JSON API
     ▼
Node.js 统一业务后端 ── SSE ──► 界面实时刷新
     │ 认证 → 角色校验 → 参数校验 → 状态机 → 审计
     ▼
SQLite：业务实体、待执行指令、遥测摘要、审计哈希链
     ▲
     │ 带模拟服务令牌的受限 tick 接口
独立设备模拟服务：回执、遥测、故障、机器人与无人机进度

外部 Agent / 本地模型 → 工具网关 → 同一业务后端 → 设备适配层
```

前端只能提交业务意图，不能直接改写数据库或绕过后端控制设备。指令经过 `pending` 到终态的独立确认，不把 HTTP 接收成功等同于设备执行成功。前端通过 SSE 通知后重新读取受授权的数据快照；连接异常时显示离线状态。

## 核心实体

| 实体 | 关系与用途 |
| --- | --- |
| 用户、会话 | 用户绑定固定角色；会话关联用户与过期时间 |
| 园区、建筑、楼层/区域 | 建筑含空间参数；设备以建筑编号与楼层定位 |
| 设备、指令 | 设备声明能力；每个指令含主体、目标、参数、幂等键与状态 |
| 告警、时间线 | 关联设备与建筑，按顺序记录确认、派单、处理、复核、归档 |
| 巡检任务 | 关联巡检机器人、建筑路线与进度 |
| 配送单 | 关联起终点、无人设备、审批与运输状态 |
| OA 申请 | 关联业务实体，审批后产生受控的业务结果 |
| 考勤记录 | 仅业务必需的昵称、部门、班次、到岗状态 |
| 自动化策略 | 定时和场景模式的启用状态；接管时暂停 |
| 接管状态 | 当前操作者、原因、时间与受影响任务 |
| Agent 调用记录 | 输入、工具、依据、结果与风险处理 |
| 审计日志 | 前序哈希、当前哈希与事件内容；禁止普通 UPDATE/DELETE |

具体表结构与索引以 `backend/schema.sql` 为准。演示采用 SQLite 外键与唯一约束，业务状态转移在后端集中处理。空间模型和实体状态分离，后续替换视觉资产不需要改变业务 API。

## 三维方案

使用 Three.js 程序化生成建筑、道路、水体、绿化和设备，避免依赖外部模型下载。建筑由业务数据驱动，支持旋转、缩放、平移、聚焦、楼层切面、设备/建筑拾取与主题图层。树木和重复构件适合实例化绘制，限制像素比，并在组件销毁时释放 GPU 资源。

接入真实资产时：

1. 以园区局部米制坐标作为统一空间基准，另存 WGS84/CGCS2000 到局部坐标转换。
2. 建筑或构件资产使用 glTF/GLB；更大范围可使用 3D Tiles 和分级加载。
3. 在模型元数据中保留 `buildingId`、`floor`、`deviceId`，让拾取结果继续关联业务实体。
4. 采用 LOD、视锥裁剪、实例化、分块加载和纹理压缩；按现场终端验证帧率。

## 真实设备接入

默认适配器仅模拟。接入真实设备需要新增受控网关适配器，至少实现：

- `readTelemetry(device)`：读取带时间戳、质量和来源的遥测。
- `sendCommand(command)`：提交指令，返回网关接收结果，不直接标记设备成功。
- `onAcknowledgement(receipt)`：校验设备身份、关联 command ID、处理重复/乱序回执。
- `checkHealth(device)`：心跳、离线、协议错误、重试退避。

控制能力必须来自后端设备字典；真实网关应校验消息签名/证书、限定命令范围、设置硬件安全互锁。不要将传感器数据或模型生成文本当作新增权限。MQTT/BACnet/Modbus 等协议应终止在网关侧，不向浏览器暴露设备凭据。

模拟 tick 接口仅供本机独立模拟服务使用，必须通过令牌校验；正式部署应关闭该入口，使用具有独立身份的设备回执 API。高风险消防、人员疏散与无人飞行必须经过实际安全方案、法规和现场联调，演示预案不可直接投产。

## 人工接管与恢复

人工接管具有后端统一的门禁状态。管理员再次输入密码后，系统停止接受所有 Agent 工具请求，暂停自动化策略执行，取消尚未执行的自动指令，并把运行、排队、返航中的无人任务暂停在安全位置；管理员可逐项召回或调度，也可通过 `/api/commands/:id/cancel` 停止尚待回执的人类联动指令。已有终态记录保持不变，取消指令不会直接改变设备状态。当前操作者、接管时间与影响范围保留在数据库和审计中。

解除接管前检查高危消防告警是否至少完成复核、控制指令是否终结、模拟器心跳是否正常。恢复权限不等同于恢复所有旧任务：任务需要重新调度或继续，避免事故前的自动动作在环境变化后立即重放。

## 生产加固

当前服务绑定本机回环地址，适合离线展示与开发。生产环境应增加 HTTPS 与可信代理配置、集中身份和会话、持久消息队列、数据库迁移版本管理、速率限制、独立审计留存、备份与灾难恢复、跨站请求防护策略、真实设备回执签名、前后端监控、机器人路径安全和软件供应链扫描。
