## 本地运行

需要 Node.js 24 及 npm。完整步骤、六角色账号和环境变量见 [README](../README.md)。默认演示账号为 `admin`，密码为 `Bailuwan2026!`；仅用于本机演示。

```powershell
npm install
npm run build
npm start
```

默认应用入口为 `http://127.0.0.1:8787/`，进度页为 `http://127.0.0.1:8787/progress.html`。`npm start` 同时启动后端和设备模拟器。已有构建时，Windows 的 `START-BACKGROUND.cmd` 与 `STOP.cmd` 提供后台启动和停止入口；服务日志位于 `.runtime/`。运行过程中的数据保存在 SQLite 中，重启后保留。

## 后续接入顺序

1. 用真实建筑与设备资产替换模拟数据，统一坐标、楼层和设备编号；通过同一业务 API 保持现有交互。
2. 引入认证设备网关、带签名回执、遥测质量与协议适配；先只读监测，再逐项启用经过现场确认的控制能力。
3. 接入本地模型与受限服务身份，维持现有工具白名单、风险确认和接管门禁。
4. 按实际组织规则扩展排班、巡检计划、路线网络、审批编排和应急预案配置。
5. 完成 HTTPS/SSO、集中数据与消息服务、备份、监控、审计外部存证、压力与安全测试；消防与无人飞行另行完成现场安全和合规验收。
